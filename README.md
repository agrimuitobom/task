# 学生タスク管理アプリ

高校生向けのシンプルなタスク管理アプリケーションです。

## 機能

### 1. やるべきことリスト
- タスクの追加・削除
- タスクの完了/未完了の切り替え
- シンプルで使いやすいインターフェース

### 2. 時間割管理
- 月曜日〜金曜日の時間割を登録
- 各曜日で最大6時間目まで対応
- 科目ごとに登録・削除が可能

### 3. 科目ごとの宿題管理
- 科目名、内容、期限を登録
- 期限までの残り日数を自動表示
- 完了/未完了の管理
- 期限順に自動ソート

## 使い方

1. `index.html` をブラウザで開く
2. 上部のタブで機能を切り替え
3. データは自動的にブラウザに保存されます（LocalStorage使用）

### やるべきことリストの使い方
1. テキスト欄にタスクを入力
2. 「追加」ボタンをクリック
3. チェックボックスで完了/未完了を切り替え
4. 「削除」ボタンで不要なタスクを削除

### 時間割の使い方
1. 曜日ボタンで登録したい曜日を選択
2. 時間目を選択
3. 科目名を入力
4. 「追加」ボタンをクリック

### 宿題管理の使い方
1. 科目名を入力
2. 宿題の内容を入力
3. 期限を選択（任意）
4. 「追加」ボタンをクリック
5. 完了したら「完了」ボタンをクリック

## 技術仕様

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage（データ永続化）

## ブラウザ対応

モダンブラウザ（Chrome, Firefox, Safari, Edge）に対応しています。

## データの保存

すべてのデータはブラウザのLocalStorageに保存されるため、ブラウザのキャッシュをクリアするとデータが失われます。
